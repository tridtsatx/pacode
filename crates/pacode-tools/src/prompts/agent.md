Run work in parallel with subagents. `spawn` returns an agent id immediately; the finished agent's report is delivered to you as a message — continue working or end your turn rather than polling. A `kind` names a subagent type defined in `<cwd>/.pacode/agents/*.md` or the global config's `agents/` dir; the file supplies the brief, tools and model. Run `kinds` (or `list`) to see which kinds this session has — do not invent a name. `stop` cancels; `continue` resumes a stopped agent with its context intact; `ask_status` delivers a brief status at your next step. Subagents cannot spawn agents.
