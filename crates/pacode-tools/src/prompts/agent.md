Run work in parallel with subagents. `spawn` returns an agent id immediately; the finished agent's report is delivered to you as a message — continue working or end your turn rather than polling. A `kind` names a subagent type defined in `<cwd>/.pacode/agents/*.md` or the global config's `agents/` dir; the file supplies the brief, tools and model. Run `kinds` (or `list`) to see which kinds this session has — do not invent a name. `stop` cancels; `continue` resumes a stopped agent with its context intact; `ask_status` delivers a brief status at your next step. `send` messages your subagent: a running one reads it at its next step, one that has ended is resumed with it. `send` or `continue` on an agent the user stopped asks the user directly whether to resume it; if they keep it stopped, leave it. An `<agent_question>` means that subagent is blocked until you answer with `send` — answer promptly, asking the user with `ask_question` first when the decision is theirs; ending your turn without an answer lets it proceed on its own judgment. Subagents cannot spawn agents.
