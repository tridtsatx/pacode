Read a file. Each line is returned as `LINE#HASH| text` (1-based line, 2-char content hash); `edit` addresses lines by these anchors, so copy them exactly and never include them in new text. Lines over 2000 chars are shown cut but stay anchored. A listing that stops short ends with `— N more lines; read with offset=…`. Text files over 8 MiB are not read whole: without offset/limit only the first 2000 lines are shown; page on with offset/limit (streamed by range) or search with grep. Output above the cap is cut head+tail and the full size is reported. `anchors:false` gives plain numbering. Binary files are refused. Reading a file is what lets you change it later with `edit`/`write`. Big source files come back as an outline (signatures, first body lines, closing lines; `… N lines hidden (La-Lb) …` markers between): hidden lines have no anchors and do not count as read, so before editing them show them with `symbol` (`Foo::bar`) or `expand` (`["44-80"]`); `mode:"full"` reads everything.
