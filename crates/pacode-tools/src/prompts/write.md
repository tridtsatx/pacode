Create or overwrite a file with the given content. Parent directories are created. Prefer `edit` for changes to existing files: a full overwrite is rejected when it would revert lines another agent changed after your read. New files need no prior read. Other agents may be editing the same files concurrently. You must `read` an existing file before changing it. A change that would overwrite lines someone else modified after your read is rejected; the rejection names who changed which lines and shows them with fresh anchors, which count as read, so retry directly (or re-read only the indicated line ranges, never the whole file). Changes elsewhere in the file are reported but do not block you.
