Apply hashline edits to several files at once, atomically: `files` = [{path, ops}] with the same `ops` and `LINE#HASH` anchors as `edit`. Every anchor in every file is verified first; if any is stale nothing is written and the current anchored lines are returned. Fallback form (avoid): `path` + `edits` [{old_string, new_string, replace_all}] applied in order to one file. Other agents may be editing the same files concurrently. You must `read` an existing file before changing it. A change that would overwrite lines someone else modified after your read is rejected; the rejection names who changed which lines and shows them with fresh anchors, which count as read, so retry directly (or re-read only the indicated line ranges, never the whole file). Changes elsewhere in the file are reported but do not block you.
